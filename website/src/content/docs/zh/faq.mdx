### 容器是否提供 SSH 访问？

不提供。镜像不运行 SSH 守护进程。请 SSH 到 Docker 宿主机，运行 `scripts/shell`，并用 tmux 保持会话。

### 是否有浏览器产品界面或本地 Web 端口？

没有。Compose 不发布应用 HTTP 端口。入口是 `scripts/shell` / `scripts/tmux`。

### 可以删掉不用的卷吗？

不可以。启动与迁移声明全部六个根目录。请始终挂载 workspace、config、data、logs、models、backups。

### 工具可以自我更新吗？

没有受支持的自更新流程。请更换镜像版本并遵循仓库中的显式升级流程。

### 为什么 `docker compose down` 会保留文件？

命名卷生命周期长于容器。`docker compose down -v` 会删除它们，因此不在常规说明中出现。

是的——MIT 许可证。
