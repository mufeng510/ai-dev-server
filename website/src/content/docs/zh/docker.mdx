## Compose 服务

提交的 Compose 项目名为 `ai-dev`。主服务：

- 镜像：`${AI_DEV_IMAGE:-docker.io/jerry0510/ai-dev:latest}`
- 工作目录：`/workspace`
- 重启策略：`unless-stopped`
- 先丢弃能力再仅恢复所有权修复所需能力
- 挂载六个命名卷，以及宿主机 `/var/run/docker.sock`（读写）
- 健康检查：`ai-dev-health`

Compose 文件中**没有发布端口**。

## 命名卷

| 卷 | 挂载点 | 作用 |
| --- | --- | --- |
| workspace | `/workspace` | 项目与仓库本地状态 |
| config | `/config` | 凭据与版本化用户配置 |
| data | `/data` | 缓存等数据 |
| logs | `/logs` | 日志与结构化事件 |
| models | `/models` | 模型产物 |
| backups | `/backups` | 备份材料 |

`docker compose down` 会保留命名卷；`docker compose down -v` 会删除它们，因此不在常规说明中出现。

## 镜像模型

- 基础：摘要固定的 Ubuntu 24.04
- 架构：amd64 与 arm64
- `versions.env` 固定工具版本
- 禁用运行时自更新；升级来自审阅后的镜像重建/标签
